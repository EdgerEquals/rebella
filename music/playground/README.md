# Rebella Music Playground (music/playground/)

Generated by `_playground.py` (one hook line in `_generator.py`). Page: `music/playground/index.html`.
Everything is made live in the browser with Tone.js 15.1.22 (self-hosted in `vendor/tone/`, MIT, loaded only after the first tap and only if an AudioContext exists). No microphone, no audio files, nothing sent anywhere. Saved locally: band + flavour (`rebella.playground.v1`), mute (`rebella.playground.muted`), dial order per session (sessionStorage).

## Files
- `_body.html` page body, `playground.css`, `js/playground.js` (dial, radio player, follow-the-radio, instruments, band, sequencer, effects, Dad's ladder demo; inline copy of the help dictionary)
- `js/help-orb.js` the reusable help orb, `data/help.json` Playground help entries
- `data/genres.json` dial detents with bpm/key/mode/flavour tags, `data/channels.json` indie channel registry (all placeholders: ids null, approvedByDad false)
- `vendor/tone/` Tone.js build + LICENSE.md + VERSION.md

## Help orb: 3-line integration for any Rebella page
```html
<script src="music/playground/js/help-orb.js" defer></script>
<script>addEventListener('DOMContentLoaded',function(){HelpOrb.init({dict:['data/help.json'],headerSlot:'.topbar .tagline',footerSlot:'footer .strip a'})});</script>
<!-- then mark controls: <button data-help="my-key">…</button> -->
```
- `HelpOrb.init({dict, headerSlot, footerSlot})`. `dict` is an object, a JSON URL, or an array of both (merged left to right, so a page's own entries extend the site's). Entries: `{ "key": { "title": "...", "what": "...", "try": "..." } }`.
- Slots default to `[data-help-slot=header]` / `[data-help-slot=footer]`, then `.topbar .tagline` / `footer .strip a`. The module only swaps their text (with a 0.382 s crossfade) and restores the original nodes afterwards; it never creates boxes or changes styling.
- One orb per page (a second `init` is ignored, extra `.help-orb` elements are removed). Drag (Pointer Events + pointer capture, `touch-action:none` on the orb only) or keyboard: focus the orb, Enter for pick mode, arrows/Tab to move, Enter to explain, Escape to stop. A plain tap explains the orb itself.
- Highlight while picking: `html.help-picking [data-help]` gets a tint and glow drawn with `box-shadow` only (no layout shift), pulsing at 2.618 s with golden-angle delays in `--help-delay`; the target under the orb gets `.help-target` (stronger tint, 1.618 s). Reduced motion: colour only.
- Keep-clear: the orb docks bottom-left and slides up to avoid iframes / `[data-help-keepclear]` (hard rule) and controls (best effort).
