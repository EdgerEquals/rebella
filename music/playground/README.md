# Rebella Music Playground (music/playground/)

Generated by `_playground.py` (one hook line in `_generator.py`). Page: `music/playground/index.html`.
Everything is made live in the browser with Tone.js 15.1.22 (self-hosted in `vendor/tone/`, MIT, loaded only after the first tap and only if an AudioContext exists). No microphone, no audio files, nothing sent anywhere. Saved locally: band + flavour (`rebella.playground.v1`), mute (`rebella.playground.muted`), dial order per session (sessionStorage).

## Files
- `_body.html` page body, `playground.css`, `js/playground.js` (follow-the-radio, instruments, band, sequencer, effects, latency, Dad's ladder demo)
- `vendor/tone/` Tone.js build + LICENSE.md + VERSION.md

## Shared with the rest of Rebella (one copy each, integrated 24 Oct 2026)
- **Genre dial + radio player:** the site's one dial, `music/youtube/bonnie-radio.js` (8 detents, static, clicks, haptic, re-roll, mute, one visible youtube-nocookie mini-player). It mounts in `[data-bonnie-radio data-variant="playground"]` and tells the Playground which station it landed on with a `rebella:station` event (tags `flavour`, `bpm`, `key_root`, `mode`), and whether YouTube is playing with `rebella:radio` (the band ducks under it). The Reading music button calls `BonnieRadio.playReading()`.
- **Registry:** `music/youtube/channels.json` (genre tags live on its `genres`; the reading playlist is the entry with genre `reading`). Only Dad-approved, age-checked entries with a real id reach `stations.js`.
- **Help orb:** the site-wide `js/help-orb.js` (`HelpOrb.init({dict, headerSlot, footerSlot})`, started by `js/help-init.js`); the Playground's entries are in the site `help.json`.
