# Rebella Moderation (prototype)

Separate static site for approving/rejecting content for Rebella. Same visual system as the magazine.

- `index.html`: passcode gate + dashboard (noindex,nofollow), plus `robots.txt` (Disallow: /)
- `js/config.js`: salted passcode hash ONLY (PBKDF2-HMAC-SHA256, 250k iterations, random 16-byte salt). Generated by `build_gate.py`.
- `js/items.js`: EXAMPLE queue items (placeholder text)
- `js/app.js`: gate check (Web Crypto), sessionStorage unlock + Lock, decisions in localStorage, JSON export

## Set the passcode (same passcode as the Rebella site)
    REBELLA_SITE_PASSCODE='...' python3 build_gate.py
Never commit the plaintext. `python3 build_gate.py --unset` resets the placeholder.

## Limits
This is a client-side gate on a static host. It hides the UI from casual visitors but is not real access control:
the page source (including js/items.js) is public on GitHub Pages and in the repo. Don't put private data here.
Decisions are per-browser (localStorage) and are not shared or sent to Rebella; use Export to save them.
Needs HTTPS (or localhost) for Web Crypto.
