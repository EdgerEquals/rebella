# Rebella image credits

Every photo on Rebella is self-hosted in this repo, resized (max 800-900px) and re-compressed as JPEG.
All photos come from **Wikimedia Commons** and were chosen only if their file page marks them **CC0** or **Public domain**, which allow free reuse, changes and redistribution, including in the board editor and in boards people download. Credit is not legally required for these, but we give it anyway. Licence status was taken from each file page on 23 Oct 2026. If a file page changes or a problem is reported, swap the image out.

Stickers (`img/stickers/*.svg`) are original artwork made for Rebella. Word stickers use the Gochi Hand and Kaushan Script fonts (SIL Open Font License), converted to outlines.
